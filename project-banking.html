Case study 01

Banking Operations Dashboard

An interactive Power BI dashboard that reports banking operations, deposit trends and loan performance KPIs for business stakeholders.

TOOLSPower BI · SQL · DAX
FOCUSDeposits & loans
AUDIENCEBusiness stakeholders
GITHUBTejaskolathapully ↗

How it came together

  1. Extract with SQL.

    Wrote optimised SQL queries to extract, clean and transform data from relational databases for reporting.

  2. Model the metrics with DAX.

    Defined business metrics using DAX measures and calculated columns.

  3. Design for exploration.

    Added drill-through navigation so stakeholders can move from a headline KPI to the detail behind it.

  4. Deliver clear summaries.

    Turned data into summaries and insights on deposit trends and loan performance.

Data flow

Relational DB→SQL clean & transform→Power BI model→DAX measures→Dashboard · drill-through
